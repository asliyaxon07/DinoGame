ARDUINO DINO GAME
================

Project Overview
----------------
This project is a simple dinosaur jumping game made using an Arduino Uno and a 16x2 I2C LCD display. The player controls the dinosaur using a pushbutton and tries to avoid obstacles.

Components Used
---------------
- Arduino Uno
- 16x2 LCD display with I2C module
- Pushbutton
- Jumper wires
- USB cable for programming and power

Connections
-----------
LCD:
- VCC -> 5V
- GND -> GND
- SDA -> A4
- SCL -> A5

Pushbutton:
- One leg -> Digital pin 2
- Other leg -> GND

The button uses the Arduino's internal pull-up resistor, so an external resistor is not required.

How It Works
------------
1. When the Arduino starts, the LCD displays the game title and instructions.
2. The player presses the pushbutton to start the game.
3. A dinosaur character appears on the LCD.
4. An obstacle moves across the display.
5. The player presses the button to make the dinosaur jump.
6. If the dinosaur collides with an obstacle, the game ends.
7. The LCD displays the final score.
8. The player can press the button to restart the game.

Programming Concepts
--------------------
- Digital input using a pushbutton
- LCD initialization and text display
- Custom LCD characters using createChar()
- Conditional statements (if)
- Variables and Boolean values
- Timing with millis()
- Collision detection
- Score tracking
- Game states

Libraries Used
--------------
- Wire.h: Supports I2C communication.
- LiquidCrystal_I2C.h: Controls the LCD display.

How to Run
----------
1. Open LCD_Dino.ino in Arduino IDE.
2. Connect the Arduino Uno to the computer.
3. Select Arduino Uno under Tools -> Board.
4. Select the correct COM port under Tools -> Port.
5. Verify and upload the program.
6. Press the pushbutton to start playing.

Purpose
-------
This project demonstrates how basic electronic components and C++ programming can be combined to create a simple interactive game.
